    Get started

    Linux and macOS. Make it runnable, set it up on this machine, then open the dashboard it prints.

    chmod +x gohort
./gohort --setup                  # the admin account, listen address and TLS
./gohort serve 127.0.0.1:8080     # the web dashboard

    Everything else (models, embeddings, search, voice, email) is set up in the dashboard, under Administrator.

    Do --setup first, on loopback: until there is an admin account, the dashboard has nobody to ask for a password.

    macOS. The download is not signed by Apple, so Gatekeeper holds it back. Before the first run:

    xattr -d com.apple.quarantine gohort

    Windows. Run the Linux build under WSL2, in your Linux home folder, with bubblewrap installed. The Windows build runs chat, agents and tools that need no shell, but not shell commands or scripts: Windows has no sandbox for them, and gohort will not run them unconfined.

    Check the download. Compare its SHA-256 with the one listed beside it above.

    sha256sum gohort                  # macOS: shasum -a 256 gohort

    Updating. A running gohort updates itself from this site: Administrator, Overview, Software Update. It checks the release list's signature against the keys built into it and every file's checksum before it installs, and keeps the version it replaced so it can roll back.
